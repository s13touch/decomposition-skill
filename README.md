# decomposition-skill

Скилл для агентов, который строит **иерархическую декомпозицию функционала проекта** по документации, скриншоту, живому URL/HTML или макету Figma и выпускает набор QA-артефактов:

1. `hierarchy.md` — каноническое markdown-дерево (единственный источник истины)
2. `hierarchy.drawio` — XML-схема draw.io, построенная из дерева
3. логическая расстановка блоков схемы
4. `matrix.xlsx` — табличная матрица покрытия

Декомпозиция строго **структурная**: без валидаций, ошибок, API/backend, SQL, алгоритмов, событий, сценариев и тест-кейсов.

## Состав репозитория

```
skills/
  decomposition-qa/
    SKILL.md                          # точка входа скилла
    references/
      pipeline.md                     # этапы, артефакты, оркестрация
      hierarchy-canon.md              # канон формата дерева, нейминг, роли, исключения
      inputs-and-augmentation.md      # чтение источников + режим «Дополнение»
      xml-schema-drawio.md            # шаблон и правила генерации draw.io
      layout.md                       # алгоритм расстановки блоков
      coverage-matrix.md              # спецификация XLSX-матрицы
      examples/
        drawio-template.xml           # эталонный шаблон draw.io
        hierarchy-example.md          # пример дерева
        coverage-matrix-example.md    # пример матрицы
test/
  fixture-widget.md                   # тестовое описание фичи
  expected-hierarchy.md               # ожидаемая декомпозиция
README.md
LICENSE
```

## Установка

### Через skills CLI (рекомендуется)

```bash
npx skills@latest add s13touch/decomposition-skill --skill=decomposition-qa
```

Скилл будет установлен в `.agents/skills/decomposition-qa` текущего проекта. Добавьте `-g`, чтобы установить глобально (user-level).

> Требование: **Node.js 22+**. На Node 20 CLI падает с ошибкой `fs/promises does not provide an export named 'glob'`.

### Вручную

Скопируйте папку `skills/decomposition-qa` в каталог скиллов вашего агента:

- OpenCode / общий `.agents`: `.agents/skills/decomposition-qa/`
- Claude Code: `.claude/skills/decomposition-qa/`

## Использование

Передайте скиллу источник(и) и попросите декомпозировать функционал. Примеры запросов:

- «Разбери функционал по документации `spec.md` и собери иерархию.»
- «Дополни декомпозицию по этому скриншоту — чего не хватало?»
- «Сгенерируй draw.io-схему и матрицу покрытия из `hierarchy.md`.»

Скилл пройдёт этапы **по шагам с остановкой после каждого**: сбор контекста → иерархия → (при новом источнике) «Дополнение» → XML-схема → расстановка → матрица покрытия. После каждого этапа — чек-лист и ожидание подтверждения.

**Главный шлюз — после иерархии.** Сначала всегда выводится иерархический список; пользователь либо присылает правки, либо подтверждает его, и только после подтверждения агент идёт дальше. Спецификацию см. в `skills/decomposition-qa/references/checkpoints.md`.

Артефакты складываются в `.scratch/<feature-slug>/decomposition/`.

## Тестирование

1. Установите скилл (см. выше).
2. В новом чате попросите: «Декомпозируй функционал из `test/fixture-widget.md`».
3. Сравните полученную иерархию с `test/expected-hierarchy.md`.

Что проверять:

- [ ] Формат дерева: табуляция + дефисы, контейнеры `(+)`, без символов `├──`.
- [ ] Отображаемые элементы именованы через «Отображение …».
- [ ] Нет валидаций, ошибок, API/backend, сценариев, тест-кейсов.
- [ ] Роли: при отличии < 70 % — одна ветка + «Дельта», а не два дерева.
- [ ] Этапы 2–4 не меняют состав и порядок элементов дерева.

Дополнительно можно проверить, что `.drawio` открывается в [draw.io](https://app.diagrams.net/) и что в `.xlsx` контейнеры чёрные, листья синие, у родителей есть вертикальный merge.

## Требования

- Агент, поддерживающий скиллы (OpenCode, Claude Code и др.).
- Для установки через CLI — Node.js 22+.
