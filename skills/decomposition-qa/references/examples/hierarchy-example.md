# Пример канонической иерархии

```text
Открытый виджет (+)
	-Опция настройки виджета (+)
		--Открытие модального окна настроек. (+)
			---Опция включения / выключения звуков уведомлений.
			---Опция включения / выключения уведомлений.
	-Отображение иконки выключенного звука.
	-Опция закрытия виджета
	-Опция поиска. (+)
		--Отображение подсказки "Поиск чатов".
		--Отображение иконки "лупа".
		--Активация опции поиска. (+)
			---Отображение найденного чата. (+)
				----Отображение названия чата.
				----Переход в найденный чат.
			---Отображение подсказки "Ничего не найдено".
```

Разбор:

- `Открытый виджет (+)` — корневой контейнер (глубина 0).
- `Опция настройки виджета (+)`, `Отображение иконки…`, `Опция закрытия виджета`, `Опция поиска. (+)` — прямые потомки (глубина 1).
- `Отображение …` — конечные элементы либо контейнеры отображаемых блоков.
- Контейнеры, раскрытые в отдельную схему: `Открытый виджет`, `Опция настройки виджета`, `Открытие модального окна настроек`, `Опция поиска`, `Активация опции поиска`, `Отображение найденного чата`.

## Пример с дельтой роли

```text
Авторизованный пользователь / Участник чата (+)
	-Список чатов (+)
		--Отображение названия чата.
		--Переход в найденный чат.
	-Отображение счётчика непрочитанных диалогов.

Дельта для роли "Родитель" (< 70% отличий)
	-Нет элемента списка "Чат класса"
	-Отображение уведомления о бане ребёнка-ученика
```
