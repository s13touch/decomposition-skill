# Пример матрицы покрытия

Соответствие иерархии и таблицы.

## Иерархия

```text
Закрытый виджет (+)
	-Отображение логотипа (+)
		--Открытие виджета
	-Отображение счётчика непрочитанных диалогов. (+)
		--Отображение значения 1-9
		--Отображение значения 9+
	-Отображение уведомления "Уведомления выкл."
```

## Матрица (.xlsx)

| A | B | C |
|---|---|---|
| **Раздел/функция** | **Раздел/функция** | **Раздел/функция** |
| Закрытый виджет | Отображение логотипа | Открытие виджета |
|  | Отображение счётчика непрочитанных диалогов. | Отображение значения 1-9 |
|  |  | Отображение значения 9+ |
|  | Отображение уведомления "Уведомления выкл." |  |

Пояснения:

- Столбцы A/B/C = глубины 0/1/2.
- Ячейка A2 «Закрытый виджет» объединена вертикально на строки 2–5 (весь блок).
- Контейнеры («Закрытый виджет», «Отображение логотипа», «Отображение счётчика непрочитанных диалогов.») — чёрные, с вертикальным merge.
- Конечные элементы («Открытие виджета», «Отображение значения 1-9», «Отображение значения 9+», «Отображение уведомления …») — синие, без merge.
- Пометка `(+)` в тексте ячеек отсутствует.
- «Отображение логотипа» стоит в строке родителя (первый ребёнок — в строке родителя).
