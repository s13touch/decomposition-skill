# Матрица покрытия (XLSX)

Преобразование готовой иерархии («матрёшки») в табличную матрицу покрытия формата Excel/Google Таблиц: «лесенка», объединение ячеек, цвета. Иерархия — единственный источник истины: не анализируй документацию, не декомпозируй, не меняй состав/порядок, не добавляй тест-кейсы/валидацию/ошибки/API/backend.

## Входные данные

1. Готовая иерархия (табуляция + дефисы; контейнеры `(+)`).
2. Опционально — пример готовой матрицы для копирования визуального стиля.

## Что должно быть видно после открытия

- Иерархия «лесенкой» по столбцам.
- Контейнеры `(+)` — чёрным; конечные элементы — синим.
- Заголовки столбцов — жирным.
- Родительские блоки с вертикальным merge на все строки потомков.

## Структура таблицы

- **Строка 1 (заголовки):** в **каждом** используемом столбце значение `Раздел/функция`, **жирным**, чёрным, выравнивание по центру (гориз.) / середине (верт.).
- **Столбцы = глубина:** корень → столбец **A** (глубина 0), ребёнок → следующий справа (B, C, D…). Число столбцов = максимальная глубина + 1.
- **Строки:** каждый узел занимает строку; порядок обхода — preorder (как в иерархии).

## Раскладка «лесенкой» (staircase)

- Каждый узел ставится в столбец своей глубины.
- **Родитель и его первый ребёнок — в одной строке** (родитель слева, первый ребёнок справа).
- Последующие siblings — ниже, каждый с новой строки (или продолжают свою ветку).
- **Обязательный вертикальный merge:** если узел имеет потомков более чем на одну строку, его ячейка объединяется по вертикали на весь диапазон строк поддерева. **Горизонтальные merge не используются.**
- Пустые ячейки: заполняются только столбцы, где есть узел ветки; остальные оставлять пустыми (не ставить `-`, `—`, `n/a`).
- Несколько корней: последовательно сверху вниз в столбце A, каждый — отдельный блок со своим merge; поддеревья не смешивать.
- Текст в ячейках: пометку `(+)` **убрать**; остальной текст сохранить как в иерархии (включая кавычки и пояснения в скобках). Не добавлять префиксы «Раздел:», нумерацию, markdown.

## Цвета

| Тип элемента | Признак в иерархии | Цвет текста |
|---|---|---|
| Контейнер / раздел | есть `(+)` | чёрный `#000000` |
| Сущность / конечный элемент | нет `(+)` | синий `#0000FF` |
| Заголовок столбца | — | чёрный + bold |

Цвет — на шрифт ячейки, не на заливку (если пример не требует иного). Оформление: тонкие границы, wrap, вертикальное выравнивание по центру, ширина ~28–35 символов. **Excel Table / ListObject поверх merge не создавать** (несовместимы с объединёнными ячейками).

## Пример скелета

Иерархия: `Закрытый виджет (+)` → логотип `(+)` → «Открытие виджета»; счётчик `(+)` → «1-9», «9+»; уведомление.

| A | B | C |
|---|---|---|
| Раздел/функция | Раздел/функция | Раздел/функция |
| Закрытый виджет | Отображение логотипа | Открытие виджета |
|  | Отображение счётчика непрочитанных диалогов. | Отображение значения 1-9 |
|  |  | Отображение значения 9+ |
|  | Отображение уведомления "Уведомления выкл." |  |

(«Закрытый виджет» — чёрный, A объединена на все строки блока; логотип/счётчик — чёрные; «Открытие виджета», «1-9», «9+», уведомление — синие.)

## Алгоритм

```text
function emit(node, depth, row):
    place node at (row, depth); start = row
    if node has no children: return row + 1
    row = emit(first_child, depth + 1, row)          # первый ребёнок — в строке родителя
    for each next_child in children[1:]:
        row = emit(next_child, depth + 1, new_row)   # новые строки
    end = row - 1
    if end > start: merge vertically cell (start..end, depth)
    return row

function build_matrix(roots):
    create sheet
    write header "Раздел/функция" in every used column, bold, black
    row = first_data_row
    for root in roots:                                # порядок как в иерархии
        row = emit(root, depth=0, row)
    apply fonts: containers -> black; leaves -> blue
    save as .xlsx
```

Глубина 0 = столбец A, 1 = B и т. д.

## Формат выхода

- Файл `.xlsx`: один лист (имя из фичи, например «WEB версия»), нативные цвета и merge, без макросов.
- По умолчанию — только `.xlsx`. По запросу: `.csv` (без гарантии цветов/merge), `.html` с цветами и `rowspan`.
- Исходную иерархию не перезаписывать.

## Чек-лист перед выдачей

- [ ] Число узлов в таблице = числу элементов иерархии (каждый ровно раз).
- [ ] Порядок обхода = порядок в иерархии (preorder).
- [ ] Заголовки = `Раздел/функция`, все bold.
- [ ] Все бывшие `(+)` — чёрные, все без `(+)` — синие.
- [ ] У родителя со span > 1 есть вертикальный merge.
- [ ] Первый ребёнок всегда в строке родителя.
- [ ] Файл открывается без потери цветов.
- [ ] Нет Excel Table, ломающей merge.
