# Тестовая фича: «Заключение договора» (фрагмент документации)

> Это тестовое описание для проверки скилла `decomposition-qa`. По нему нужно собрать иерархическую декомпозицию.

## Экран

Модальное окно **«Заключение договора»**. Открывается по кнопке «Заключить договор» в списке детей.

Содержимое модального окна:

- Заголовок «Заключение договора».
- Крестик закрытия окна.
- Текст «Выберите ребенка, на которого хотите заключить договор».
- Список детей. В списке есть:
  - элемент «Новый ученик» — открывает форму создания;
  - элементы существующих детей: миниатюра с инициалами, имя «Фамилия Имя», подсказка с описанием шага процесса, кнопка «Перейти».
- Кнопка «Заключить договор».

Число детей может быть разным (список динамический). Если детей нет — по центру списка крестик и текст «Ничего не найдено».

## Роли

Экран «Заключение договора» доступен только авторизованному пользователю-родителю. Неавторизованный пользователь видит вместо него экран входа (не является частью этой фичи). Другой роли (сотрудник) этот экран недоступен.

Отличий в UI между родителями разных типов нет.

## Поведение (для справки)

- Нажатие на ребёнка выбирает его; выбранный подсвечивается.
- Кнопка «Заключить договор» недоступна, если ребёнок не выбран (валидация обязательности).
- При попытке заключить договор без согласия выводится ошибка «Необходимо согласие» (текст ошибки).
- Максимальная длина ФИО — 120 символов (валидация формата).
