# Ожидаемая декомпозиция (эталон для теста)

По тестовой фиче `test/fixture-widget.md` корректная декомпозиция выглядит примерно так:

```text
Авторизованный пользователь (+)
	-Модальное окно "Заключение договора" (+)
		--Отображение заголовка "Заключение договора"
		--Отображение описания "Выберите ребенка, на которого хотите заключить договор"
		--Крестик закрытия окна
		--Список детей (+)
			---Новый ученик (+)
				----Открытие формы создания ученика
			---Активный ребенок (+)
				----Отображение миниатюры с инициалами
				----Отображение имени "Фамилия Имя"
				----Отображение подсказки с описанием шага процесса
				----Кнопка "Перейти"
			---Отображение заглушки "Ничего не найдено"
		--Кнопка "Заключить договор"
```

## Что должно получиться и чего быть не должно

**Должно быть:**

- Формат: табуляция + дефисы; контейнеры помечены `(+)`.
- «Отображение …» у отображаемых элементов (заголовок, описание, инициалы, имя, подсказка, заглушка).
- Кнопки/крестик — интерактив, без префикса «Отображение».
- Роли: различие выражено незначительно (< 70 %) → **одна ветка** «Авторизованный пользователь» + (при необходимости) «Дельта», а не отдельные деревья для неавторизованного/сотрудника.
- Валидации и ошибки **исключены**.

**Не должно быть:**

- Валидаций: «недоступна, если ребёнок не выбран», «максимальная длина ФИО 120 символов».
- Ошибок: «Необходимо согласие».
- Отдельной ветки «Неавторизованный пользователь» (у него нет собственного UI этой фичи).
- Отдельной ветки «Сотрудник» (роль в документации для этой фичи недоступна).
- Символов дерева `├──`, `└──`.
